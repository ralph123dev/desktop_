## 🚀 Démarrage en 10 Minutes

### 1. Lire
```
Lisez: 00_READ_ME_FIRST.txt ou START_HERE.md
```

### 2. Configurer Supabase
```
1. Allez sur https://supabase.com
2. Créez un compte gratuit
3. Créez un projet
4. Copiez les credentials
5. Collez dans .env
```

### 3. Installer
```bash
bash run.sh              # macOS/Linux
# ou
run.bat                  # Windows
```

### 4. Utiliser
Lancez l'application et explorez le Dashboard.
