Projet : Stark Log — Dossier technique
=====================================

1. Vue d'ensemble
- Objectif : Application desktop Python (CustomTkinter) pour monitoring système, gestion du cache DNS, nettoyage de RAM, gestionnaire de fichiers et chat communautaire.
- Point d'entrée : main.py

2. Environnement et dépendances
- Python recommandé : 3.8+
- Dépendances principales (voir requirements.txt) : customtkinter, psutil, pillow, supabase, python-dotenv, matplotlib, numpy, requests.
- Fichier dépendances : requirements.txt

3. Structure du projet
- racine
  - main.py (bootstrap + charge `ui.app`)
  - config/ (settings, constants, thème)
  - services/ (auth_service.py, chat_service.py, cloudinary_service.py, database.py, network_info.py, supabase_client.py, system_monitor.py)
  - ui/ (app.py, frames/, widgets/)
  - supabase/migrations/ (SQL de migration)
  - scripts : run.bat, run.sh

4. Architecture et responsabilités
- UI : `ui.app` orchestre la fenêtre principale et charge les frames (dashboard, storage, chat, settings, auth). Widgets spécialisés (ram_monitor, process_list, upload_progress) fournissent composants réutilisables.
- Services : couche métier / intégration
  - `system_monitor.py` : collecte metrics via psutil
  - `supabase_client.py` & `auth_service.py` : gestion auth et opérations Supabase
  - `chat_service.py` : logique d'envoi/réception des messages
  - `database.py` : accès local/abstraction DB si présent
  - `cloudinary_service.py` : gestion upload (si utilisée)
- Config : `config/settings.py` pour les réglages locaux et thèmes.

5. Base de données & migrations
- Migrations SQL situées dans : supabase/migrations/
- Backend : Supabase (variables d'environnement : SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY) — utilisez .env ou variables système.

6. Exécution et développement local
- Créer venv : `python -m venv venv` puis activer.
- Installer : `pip install -r requirements.txt` ([requirements.txt](requirements.txt)).
- Variables d'environnement : créer `.env` à la racine avec clés Supabase.
- Lancer : `python main.py` ou via `run.bat` / `run.sh`.
- Scripts utiles (définis dans package.json) :
  - `python3 -m py_compile` pour vérifier que les fichiers Python compilent.
  - `python3 main.py` (start)
  - `python3 verify.py` (verify)
  - `python3 test_imports.py` (test)
